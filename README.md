# Trafalgar Landing Page Using Tailwind CSS

A responsive Trafalgar healthcare landing page built with **HTML** and **Tailwind CSS**, based on the provided Figma design reference.

## 📌 Assignment Description

The goal of this assignment is to recreate the Trafalgar Landing Page from the provided Figma design using **Tailwind CSS**.

The website focuses on responsive layouts, typography, colors, spacing, buttons, images, and overall visual structure according to the reference design.

## ✨ Features

* Responsive Trafalgar landing page
* Mobile, tablet, and desktop layouts
* Navigation bar
* Hero section
* Healthcare service sections
* Service cards
* Healthcare provider section
* Download/app section
* Customer/testimonial section
* Article/blog section
* Footer
* Responsive buttons and navigation
* Tailwind CSS utility classes for styling

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS  

> No JavaScript is used in this project.

## 📱 Responsive Design

The page is designed to work across different screen sizes:

* 📱 Mobile
* 📱 Tablet
* 💻 Desktop

Tailwind CSS responsive utility classes are used to adapt the layout, spacing, typography, and components for different screen sizes.


2. Open the project folder:

```bash
cd Trafalgar-Landing-Page-Using-Tailwind-CSS
```

3. Open `index.html` in your browser.
